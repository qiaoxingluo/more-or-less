通用调度框架（五个案例共用）

工程没有 main()，由 Runner 加载 Test.dll 后按 .tmf 中的 FuncList 顺序按名调用导出函数。任一步 Fail → 按该步 Sbin/Hbin 分档并终止；全部通过 → SetPassBin 置 Bin 1。
Runner 加载 Job + Test.dll→ ProjectInit→ SiteInit→ ① FuncList 逐项执行→ ② 每项 CheckResultAndBin 判限→ SetPassBin → Bin 1→ SiteReset / ProjectReset
