## 1. 选型理由与案例定位

本实训室已有的六个案例中，ADC0832 覆盖的是 **模数（A→D）** 方向。**DAC0832 正好是它的镜像（D→A）**，两者构成完整的数据转换闭环，是本课程目前缺少的一块。

| 对比项 | ADC0832（已有） | DAC0832（本方案） |
|---|---|---|
| 转换方向 | 模拟 → 数字 | 数字 → 模拟 |
| 分辨率 | 8 bit | 8 bit |
| 接口 | 串行（CLK/DI/DO/CS） | **8 位并行总线** |
| 输出性质 | 数字码 | **电流输出**（IOUT1/IOUT2） |
| 必需外设 | AWG 提供模拟激励 | **外部运放做 I/V 转换 → LM358** |
| 主要误差参数 | Offset / Gain / DNL / INL / SNR / ENOB | Offset / Gain / DNL / INL / **单调性** / **建立时间** |

**教育价值**：本案例把 ADC、DAC、运算放大器三块内容串成一个完整链路，DAC 的电流输出必须靠 LM358 转成电压才能测量 —— 正好复用 LM358 案例中已经掌握的双电源供电与 BPMU 测量方法。

⚠️ **重要前提**：半导体工程师实训平台上**没有 DAC 成品模块**，本案例必须在**通用器件接口板**上用面包板自行搭建硬件（与 CD4511 案例性质相同）。

## 2. 器件结构与引脚

DAC0832 内部为硅铬（SiCr）**R-2R 梯形电阻网络**，带两级锁存（双缓冲），可用直通模式、单缓冲或双缓冲。

| 引脚 | 名称 | 方向 | 测试中的角色 |
|---|---|---|---|
| 1 | CS | 输入 | 片选，低有效 |
| 2 | WR1 | 输入 | 第一级锁存写，低有效 |
| 3 | AGND | 电源 | 模拟地 |
| 4~7, 13~16 | DI3~DI0, DI7~DI4 | 输入 | 8 位数据总线 |
| 8 | VREF | 输入 | 基准电压输入（内部约 15 kΩ） |
| 9 | Rfb | 输入/出 | 内部反馈电阻，与 R-2R 网络匹配 |
| 10 | DGND | 电源 | 数字地 |
| 11 | IOUT1 | 输出 | 电流输出 1（主输出） |
| 12 | IOUT2 | 输出 | 互补电流输出（IOUT1 + IOUT2 = 常数） |
| 17 | XFER | 输入 | 第二级锁存转移控制，低有效 |
| 18 | WR2 | 输入 | 第二级锁存写，低有效 |
| 19 | ILE | 输入 | 第一级锁存使能，高有效 |
| 20 | VCC | 电源 | 正电源（推荐 5 V） |

**关键电气特性**（具体数值以你手上批次的官方 datasheet 为准）：

- 电源电压范围：+5 V ~ +15 V，绝对最大 17 V
- VREF 输入范围：±10 V
- 建立时间：典型 1 µs（满量程跳变）
- 电流输出型，不能直接当电压源使用

## 3. 测试硬件搭建

DAC 输出是电流，必须先转成电压才能被测量。标准接法是**反相 I/V 转换**，利用芯片内部自带的 Rfb（免去外部电阻匹配）：

```
                 内部 Rfb (≈15kΩ, 已在片内)
        ┌───────────── Rfb ─────────────┐
        │                               │
        │        ┌──────┐               │
 IOUT1 ─┴────────┤ −    │               │
                 │  LM358├──── VOUT ────┘
        GND ─────┤ +    │        │
                 └──────┘        │
                  ±电源          └──→ 送去 BPMU / DGT 测量
```

**要点：**

1. **IOUT1 接运放反相端，运放同相端接地**。这是标准电流求和接法，IOUT1 流出的电流全部经 Rfb 反馈到输出端。
2. **LM358 必须双电源供电**。因为输出为负电压 —— 这解释了为什么 LM358 案例里用到了 4 路 DPS（±V 各两路），本案例可以直接复用那套供电思路。
3. **VREF 建议单独用一路 DPS 或 AWG 提供**，不要用 VCC 兼任。这样方便做第 7 节的乘法特性扫描。
4. **去耦**：VCC 到 DGND 就近放 0.1 µF 陶瓷电容；AGND 与 DGND 在芯片下方单点汇合。
5. **直通模式接线**：ILE 接高、CS 与 WR1 并接（构成 WR 信号）、WR2 与 XFER 并接并接地，即可让数据总线一写入立刻更新输出，测试最方便。

**注意事项**：若希望输出为正电压，可在 LM358 后再加一级反相器（此时总共需要两个运放单元，LM358 内含两路，刚好够）。

## 5. 静态参数理论基础

DAC 的静态误差全部建立在「**码 vs 电压**」的理想对应关系上。以 VREF = 5.000 V、内部 Rfb 反相接法为例：

| 概念 | 公式 | 本例数值 |
|---|---|---|
| 1 LSB 步进 | VREF / 2⁸ = VREF / 256 | **19.53 mV** |
| 满量程 FS | VREF × 255 / 256 | **4.980 V** |
| 理想传递函数 | V(n) = −VREF × n / 256 | 码 0 → 0 V；码 255 → −4.980 V |

由此定义四个核心误差指标：

| 指标 | 定义 | 物理含义 |
|---|---|---|
| **Offset 零点误差** | 码 0 时的实际输出偏离 0 V 的量 | 整条曲线整体平移 |
| **Gain 增益误差** | 满量程点偏离理想值的量 | 曲线斜率不对 |
| **DNL 微分非线性** | 相邻码的实际步进偏离 1 LSB 的量 | 局部锯齿，最差那位决定 DAC 好不好用 |
| **INL 积分非线性** | 实际点偏离理想直线的最大距离 | 整体弯曲程度 |
| **单调性** | 码递增时输出是否单调不回退 | DNL > −1 LSB 的等价判据 |

⚠️ **注意 DAC 与 ADC 的定义差异**：DAC 的 DNL 用每个码对应的**电压步进**计算；ADC 的 DNL 用每个码对应的**码宽（输入电压区间）**计算。两者算法不同，千万别照抄 ADC0832 案例里的公式。

## 7. 逐项测试说明

### 7.0 OS_TEST — 开短路

| 项目 | 内容 |
|---|---|
| 目的 | 确认飞线、插座、继电器切换可靠，排除物理缺陷 |
| 方法 | VCC / VREF / DGND 先置 0 V；对全部 13 个 IO 脚依次通过 PPMU 抽 −100 µA、灌 +100 µA，测 ESD 保护二极管压降 |
| 建议限值 | 负向 −1.2 ~ −0.2 V；正向 0.2 ~ 1.2 V |
| 资源 | PPMU FIMV ±100 µA，电压钳位 ±2 V |
| Fail | Bin 2 |

**串扰注意**：AGND 与 DGND 在板上是单点连接的，OS 测试前必须确认两路地已经可靠短接，否则 dio 通道测量值会整体偏移。

### 7.1 ICC_TEST — 静态电源电流

| 项目 | 内容 |
|---|---|
| 目的 | 快速筛除内部短路、ESD 损伤的芯片 |
| 方法 | DPS 给 VCC 施加 5 V（可加测 15 V 作为严苛条件），全部数字输入固定为 0 或 VCC，IOUT1 空载，等待稳定后测 VCC 电流 |
| 建议限值 | 先放宽至 0.1 ~ 3 mA（见第 10 节收紧方法） |
| 资源 | DPS FVMI |
| Fail | Bin 3 |

**为什么放在第二位**：IDD/ICC 异常往往伴随后续所有参数失效，早筛可以省测试时间。

### 7.2 IOUT_LEAK_TEST — 输出漏电流

| 项目 | 内容 |
|---|---|
| 目的 | 验证输出级在关断状态下的漏电是否合格 |
| 方法 | 写入全 0 码，CBIT 切到直接测量电流输出（旁路 LM358），PPMU 对小电流引脚施加规定电压并测电流 |
| 建议限值 | ±1 µA 起，按样本分布收紧 |
| 资源 | PPMU FVMI，切 2 µA 小量程；CBIT 切换 K_LOAD |
| Fail | Bin 4 |

**量程提醒**：必须先大后小。首次测量用 200 µA 量程确认没有大电流，再切 2 µA 档，否则会因过载导致读数卡死（同 CD4511 案例里 IIL_TEST 的做法）。

### 7.3 DAC_STATIC_TEST — 静态参数（本案例的核心）

| 项目 | 内容 |
|---|---|
| 目的 | 求 Offset / Gain / DNL / INL / 单调性，共 5 个判据 |
| 资源 | DIO 写码 + BPMU 测电压（务必用 BPMU，不是 PPMU，精度不够） |

**执行步骤：**

1. VREF 施加 5.000 V，VCC 施加 5 V，等待上电稳定（建议 ≥ 5 ms）
2. 循环 n = 0 → 255：
   - `pattern` 或 `dio` 写入码 n 到数据总线
   - 拉低 CS/WR 完成锁存
   - 等待稳定
   - **BPMU 测量 VOUT(n)**，记入结果数组
3. 用端点法（测得 V(0) 与 V(255) 连成参考直线）计算：
   - `Offset = V(0) − 理想值(0)`
   - `Gain = [V(255) − V(0)] − −4.980 V 的理想跨度`
   - `INL(n) = [V(n) − V(0)] − n × [(V(255) − V(0)) / 255]`
   - `DNL(n) = [V(n) − V(n−1)] − [(V(255) − V(0)) / 255]`
   - 记录 MAX(INL)、MAX(DNL)，并检查所有 `V(n+1) − V(n)` 符号一致（单调性）

| 判据 | 建议限值（先用） | 说明 |
|---|---|---|
| Offset | ±1 LSB（±19.5 mV） | 8 位器件不修调，1 LSB 合理 |
| Gain | ±1 % FS（±49.8 mV） | VREF 本身精度会直接带进来 |
| DNL | ±1 LSB | 超出即可能非单调 |
| INL | ±1 LSB | 同上 |
| 单调性 | 全部 ΔV 同号 | 与 DNL > −1 LSB 等价，双保险 |

| Fail | Bin 5 |
|---|---|

⚠️ **重要限制**：本方案依赖 **LM358 作为 I/V 转换运放**，而 LM358 自身有数 mV 级失调（见 LM358 案例的 Uos 限值 ±1 V 判据窗口其实很宽）。**LM358 的失调会直接叠加进 Offset 判据**。解决办法有两条：
- 方法一：Offset 判据放宽到 ±1.5 LSB，并在报告中明确指出这是「系统级」而非「芯片级」指标；
- 方法二：改用低失调运放（如 OP07）做 I/V 转换，把这项单独隔离出来。

这是本 cases 最容易被忽视的一点，报告里务必写清楚，否则老师问「你测的是 DAC 还是运放的失调」会答不上。

### 7.4 SETTLING_TEST — 建立时间

| 项目 | 内容 |
|---|---|
| 目的 | 验证满量程跳变后多久进入并保持在 ±½ LSB 误差带内 |
| 方法 | 控制**主进位跳变**（常用于 DAC）：码从 01111111 → 10000000，以及全 0 → 全 255 的最恶劣跳变；用 DGT 高速采集 VOUT 波形，软件判定进入误差带并保持的时刻 |
| 建议限值 | ≤ 2 µs（芯片手册典型值 1 µs，留 2 倍余量） |
| 资源 | DGT（必用）+ DIO 产生码跳变 + AWG（若需要三角/正弦动态验证） |
| Fail | Bin 6 |

⚠️ **这是全案最大的坑**：你测到的建立时间是 **DAC + LM358 组合** 的建立时间。LM358 带宽约 1 MHz、压摆率约 0.3 V/µs，一个 5 V 满幅跳变光运放就要约 17 µs 才可能摆到位 —— **比 DAC 自身的 1 µs 慢十几倍**。

对应处理办法（三选一，报告里要说明选了哪个）：

| 方案 | 做法 | 代价 |
|---|---|---|
| A | 限值放宽到「系统级」，直接声明测的是 DAC+运放整体 | 最简单，但测的不是芯片指标 |
| B | **旁路运放**：CBIT 切 K_OPA，在 IOUT1 串一个取样电阻直接转成小电压，用 DGT 高阻输入采 | 需要额外电阻与继电器，信号幅度小 |
| C | I/V 转换换成高速运放（如 LM318、AD711） | 要重新搭电路 |

**建议**：教学场景用方案 A，并把「为什么测出来的不是 1 µs」作为报告里的分析亮点。

### 7.5 VREF_MULT_TEST — 基准乘法特性（可选加分项）

DAC0832 是**乘法型** DAC，VREF 可以在 ±10 V 内变化。验证输出与 VREF 成正比，可以设计：

| 条件 | 验证内容 |
|---|---|
| VREF = 2.5 V / 5 V / 10 V，码固定为 128 | 输出是否严格呈 1 : 2 : 4 比例 |
| VREF 由 AWG 施加慢变斜坡 | 输出是否随之线性变化（乘法 DAC 特性） |

| Fail | Bin 7 |
|---|---|

该项**不是必测**，但作为 Dom 部分（设计验证）很有说服力，建议课程报告里保留。

### 7.6 FUNC_TEST — 时序功能

| 项目 | 内容 |
|---|---|
| 目的 | 验证两级锁存与时序是否符合真值表，排除控制路径故障 |
| 方法 | 编写 Pattern 覆盖以下组合：`ILE=1/CS=0/WR1=0`（写入第一级）、`WR2=0/XFER=0`（转移到第二级）等，验证「写入锁存的数据不会立刻改变输出，直到 XFER 生效」这一双缓冲特征 |
| 判据 | Pattern 比较全部通过；特征值设置 1 = pass |
| 资源 | DIO Pattern + `.tim` 定义 WR/CS 脉宽与建立保持时间 |
| Fail | Bin 8 |

**这一步才真正用得上 Pattern**：前面几步都是 DC 参数测试，只有这一步需要 `.tim` 时序文件与 `.pat` 向量文件，所以 `.tim` 里的周期与脉宽必须满足 datasheet 的 WR 脉宽最小值（典型数百 ns）。

### 7.7 SetPassBin

全部通过后置 `binObj.SetBin(1)`。

## 9. 三个工程陷阱

1. **运放失调会污染 Offset 判据** —— 见 7.3。测的到底是 DAC 还是 LM358，报告必须说清楚。
2. **建立时间测的是系统而非芯片** —— 见 7.4。LM358 压摆率决定了下限。
3. **DAC 的 DNL/INL 公式与 ADC 不同** —— 见第 5 节。直接复用 ADC0832 案例的算法会得到错误结果。

额外提醒：**必须等`dac output` 稳定后再测量**。静态测试每点建议等待 ≥ 100 µs（LM358 带宽低），256 个点就是 25.6 ms+，这部分是测试时间的主要构成，也是后续优化（并行/减速)+的点。

## 10. 限值怎么定

⚠️ **不要直接抄 datasheet 当 Limit**。datasheet 给的是厂家在自家 bench 条件下的规格，而你在通用器件接口板上搭出来的电路，寄生、接触电阻、LM358 误差全部会叠加进来。

推荐流程（这也是真实量产时的标准做法）：

| 步骤 | 做法 |
|---|---|
| 1 | 限值先设**极宽**（例如 ICC 放宽到 0.1~3 mA、DNL 放宽到 ±2 LSB），目的只是**筛掉功能坏件**，不要误杀 |
| 2 | 拿 30~50 颗良品跑到全 Pass，导出每项的分布 |
| 3 | 计算均值 μ 与标准差 σ，收紧到 **μ ± 6σ** |
| 4 | 留出 **GR&R 余量**（一般要求机台重复性 ≤ 公差带的 10%），再向外扩 |
| 5 | 反过来验证：确认 50 颗良品全 Pass、人为注入的坏件全 Fail |
| 6 | 固化进 `.tmf`，之后每次换批次只做交叉验证，不重定 Limit |

这个流程可以直接写进报告，比直接贴一组数字有说服力得多。

## 11. 调试上线顺序

建议按下列顺序推进，每一步通过后再进入下一步，**不要一上来就写完整工程**：

| 步骤 | 目标 | 验证方式 |
|---|---|---|
| 1 | 硬件 Bring-up | 手焊最小电路（DAC + LM358 + 电源），用万用表/示波器确认写 0x80 输出约 −2.5 V |
| 2 | 只做 OS_TEST | 确认所有飞线接触良好 |
| 3 | 加 ICC_TEST | 确认电源电流正常 |
| 4 | 加 STATIC 的**单点**版本 | 只测 0x00 / 0x80 / 0xFF 三点，确认线性基本正确 |
| 5 | 扩展为全 256 点静态扫描 | 确认 DNL/INL 算法正确 |
| 6 | 加 SETTLING | 此时已明确误差来源 |
| 7 | 加 FUNC Pattern | 最后补时序项 |
| 8 | 跑 30+ 颗样本，收紧 Limit | 完成 |
