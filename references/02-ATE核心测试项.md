# ATE 通用测试项与实现手法

> 每条都给「怎么 force / 怎么 measure / 失败时像个什么样子」。

---

## 1. 开短路 OS / Open-Short

- **force**：PPMU FIMV ±100 µA
- **measure**：引脚电压 = ESD 二极管 Vf，正常 ±(0.2 ~ 1.2) V
- **判据**：
  - 开路 → 无电流回路 → PPMU 打到钳位 **±2 V** → FAIL
  - 对 GND/VCC 短接 → 读到 **≈ 0 V** → FAIL
  - 相邻脚短接 → 并行法下两只并联二极管分流，**读数不变，误判 PASS**（见 `03`）
- **详见**：`references/03-开短路OS方法论.md`

---

## 2. 漏电流 Leakage（IIH / IIL）

- **force**：FVMI，给 VIH（测 IIH）或 VIL（测 IIL）电压
- **measure**：流入 / 流出引脚的电流，正常在 **µA 甚至 nA 级**
- **失败形态**：栅氧击穿、ESD 损伤 → 漏电跳到几十 µA 甚至 mA
- **注意**：必须等足够长的 settling time，电容充电电流会被误计为漏电

---

## 3. 静态功耗 IDD Static

- **force**：DPS 给标称 VDD
- **measure**：pattern 停在稳态时的总电流
- **失败形态**：
  - 偏大 → CMOS 闩锁（latch-up）、内部短路、栅漏电
  - 偏小 → 内部开路、某模块没上电
- **CMOS 特性**：静态时只有漏电流，故 IDD Static 极小（µA 级），这也是 CMOS 相对 TTL 的核心优势

---

## 4. 动态功耗 IDD Dynamic

- **force**：DPS 给 VDD
- **measure**：跑一段高翻转率 pattern 时的平均电流
- **目的**：抓「静态正常但内部有短路/时钟树异常」的器件 —— 这类在 IDD Static 下看不出来

---

## 5. 输出电平 VOH / IOH 与 VOL / IOL

| 项 | force | measure | 典型判据 |
|---|---|---|---|
| **VOH / IOH** | 从引脚**拉出**规定电流 IOH（如 −4 mA） | 输出电压 | ≥ VOH（如 2.4 V @ VCC=3V） |
| **VOL / IOL** | 向引脚**灌入**规定电流 IOL（如 4 mA） | 输出电压 | ≤ VOL（如 0.4 V） |

- **失败形态**：VOH 偏低 → 上拉管导通电阻偏大；VOL 偏高 → 下拉管能力不足
- **物理意义**：这两项测的其实是输出级的**导通电阻** $R_{on} = \Delta V / \Delta I$

---

## 6. 输入阈值 VIL / VIH

- **做法**：扫描输入电压，找输出翻转点
- **目的**：验证输入的噪声容限是否达标
- **失败形态**：工艺偏移导致翻转点漂移，实际噪声容限被吃掉

---

## 7. 功能测试 Functional / Pattern

- **做法**：按真值表送激励向量，在 strobe 点比较输出
- **覆盖**：逻辑错误、时序违例、存储单元失效
- **关键参数**：
  - **Cycle / Period**：一个向量的周期
  - **Edge**：驱动沿与比较沿在周期内的位置
  - **Format**：NRZ / RZ / RO / SBC（见母文档第 7 节）
  - **Strobe**：输出采样点

---

## 8. ADC 专项

### 静态参数（ADC_Static）

| 参数 | 含义 | 失败形态 |
|---|---|---|
| Offset | 零点偏移 | 整体平移 |
| Gain_Error | 增益误差 | 满量程偏离 |
| **Miss_Code** | **失码** | 某些数字码永远不出现 |
| **DNL** | 微分非线性 | 相邻码宽度不均 → 严重时出现失码 |
| **INL** | 积分非线性 | 整体传递函数弯曲 |

做法：AWG 送缓慢斜坡，逐码采样统计码密度。

### 动态参数（ADC_Dynamic）

| 参数 | 含义 |
|---|---|
| **SNR** | 信噪比 |
| **SINAD** | 信号对噪声+失真比 |
| **THD** | 总谐波失真 |
| **ENOB** | 有效位数，$ENOB = (SINAD - 1.76)/6.02$ |

做法：AWG 送纯正弦，DGT 采样后做 FFT 分析。

---

## 9. 存储器专项：测试图样与 MBIST

存储器不能逐单元穷举（太慢），必须用**图样算法**：

| 手法 | 做法 | 覆盖的失效 |
|---|---|---|
| **棋盘 / 交替** | 偶数地址写 0x55、奇数地址写 0xAA | 地址译码故障、相邻单元耦合 |
| **March** | 按地址升序遍历，对每个单元执行一串读/写操作 | 地址译码、单元粘连、耦合 |
| **March C−** | March 的工业标准简化版 | 综合覆盖最好，业界最常用 |

实证：HK24C02 案例的 `TM_ALLEVEN_55_2K` / `TM_ALLODD_AA_2K` 就是棋盘 + 交替图样的具体实现（见 `08` 第 2 节）。

---

## 10. 测试项排列顺序的经验原则

```
OS → Leakage → IDD Static/Dynamic → VOH/IOH → VOL/IOL → VIL/VIH → Function
```

理由：

1. **OS 在最前** —— 保护测试机 + 避免给坏芯片浪费时间；
2. **先 DC 后 AC** —— 先确保每个脚的电气连接与静态特性 OK，再谈功能与时序；
3. **便宜的先跑** —— 便宜的项能拦掉大部分废品，减少后续昂贵测试的次数。
