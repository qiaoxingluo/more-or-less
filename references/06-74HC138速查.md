# 74HC138（HC138）速查

> 3-to-8 线译码器 / 解复用器，DIP-16，标准 CMOS
> 配套工程模板：`templates/HC138_OS_V1/`

---

## 1. 型号澄清 ⚠️

**"HCE138" 这个型号不存在。**

查遍公开 datasheet 库都找不到独立的 HCE138。实际应为 **74HC138**，或其厂商前缀变体：

| 型号 | 厂商 | 引脚定义 |
|---|---|---|
| **74HC138** | 通用命名 | 一致 |
| SN74HC138N | TI | 一致 |
| MC74HC138 | ON Semiconductor | 一致 |
| TC74HC138 | Toshiba | 一致 |
| CD74HC138 | TI (旧) | 一致 |

**引脚定义完全一致，测试流程通用。** 若实物丝印是别的后缀，按本文件的引脚表核对一遍即可。

### 1.1 另一个坑：74LS138 ≠ 74HC138

若实物是 **74LS138（TTL 双极型）**而非 74HC138（CMOS）：

| | 74HC138 (CMOS) | 74LS138 (TTL) |
|---|---|---|
| 输入结构 | MOS 栅极 | **双极型发射极** |
| VCC 侧 ESD 二极管 | 有 | **没有标准的** |
| OSN（下二极管） | ✓ 可测 | ✓ 可测 |
| OSP（上二极管） | ✓ 可测 | **✗ 会全体读到钳位电压** |

⚠️ 对 74LS138 跑 OSP，会得到全 pin FAIL 的假象。**必须改为只跑 OSN**，并重新标定限值。

## 2. 引脚表（DIP-16）

| 引脚 | 名称 | 方向 | 说明 |
|:--:|---|:--:|---|
| 1 | **A0** | 输入 | 地址位 0（**LSB**） |
| 2 | **A1** | 输入 | 地址位 1 |
| 3 | **A2** | 输入 | 地址位 2（**MSB**） |
| 4 | **E1** | 输入 | 使能，**低有效** |
| 5 | **E2** | 输入 | 使能，**低有效** |
| 6 | **E3** | 输入 | 使能，**高有效** |
| 7 | **Y7** | 输出 | 输出 7，**低有效** |
| 8 | **GND** | 电源 | 地 → 插槽 **b7** |
| 9 | **Y6** | 输出 | 输出 6，低有效 |
| 10 | **Y5** | 输出 | 输出 5，低有效 |
| 11 | **Y4** | 输出 | 输出 4，低有效 |
| 12 | **Y3** | 输出 | 输出 3，低有效 |
| 13 | **Y2** | 输出 | 输出 2，低有效 |
| 14 | **Y1** | 输出 | 输出 1，低有效 |
| 15 | **Y0** | 输出 | 输出 0，低有效 |
| 16 | **VCC** | 电源 | 2 ~ 6 V |

**信号脚共 14 个**：A0/A1/A2（3）+ E1/E2/E3（3）+ Y0~Y7（8）。

> 📌 注意输出引脚编号是**倒序**的：Y0 在 **15 脚**，Y7 在 **7 脚**。接线时最容易搞错。

## 3. 真值表（功能测试的核心）

**使能条件**：`E1 = 0 且 E2 = 0 且 E3 = 1`

任一不满足 → **所有输出恒为高**。

| E3 | E1 | E2 | A2 | A1 | A0 | 输出（低有效） |
|:--:|:--:|:--:|:--:|:--:|:--:|---|
| 1 | 0 | 0 | 0 | 0 | 0 | **Y0 = 0**，其余为 1 |
| 1 | 0 | 0 | 0 | 0 | 1 | **Y1 = 0**，其余为 1 |
| 1 | 0 | 0 | 0 | 1 | 0 | **Y2 = 0** |
| 1 | 0 | 0 | 0 | 1 | 1 | **Y3 = 0** |
| 1 | 0 | 0 | 1 | 0 | 0 | **Y4 = 0** |
| 1 | 0 | 0 | 1 | 0 | 1 | **Y5 = 0** |
| 1 | 0 | 0 | 1 | 1 | 0 | **Y6 = 0** |
| 1 | 0 | 0 | 1 | 1 | 1 | **Y7 = 0** |
| X | 1 | X | X | X | X | 全部为 1（禁能） |
| X | X | 1 | X | X | X | 全部为 1（禁能） |
| 0 | X | X | X | X | X | 全部为 1（禁能） |

**Pattern 最少要覆盖**：8 个有效译码状态 + 至少 3 个禁能状态（E1=1 / E2=1 / E3=0）。

## 4. 为什么 HC138 适合做 OS 教学

| 特点 | 对 OS 的意义 |
|---|---|
| 标准 CMOS | 14 个信号脚**都有完整上下二极管**，OSN / OSP 双方向都能做 |
| DIP-16 直插 | 可自焊在通用接口板上，无需定制 loadboard |
| 引脚数适中（14） | 通道够用，串行法也不会慢到不能接受，方便对比方案优劣 |
| 无内部上拉 | 不存在上拉电阻污染 OS 读数的问题（对比 HK24C02） |
| 逻辑简单 | 出错时容易区分是测试程序问题还是器件问题 |

## 5. 完整测试流程建议（OS 之后的扩展）

```
OSN_T   → OSP_T           ← 开短路（模板已实现）
  ↓
IIL_T / IIH_T             ← 漏电流，FVMI
  ↓
IDD_T                     ← 静态功耗（DPS 测总电流）
  ↓
VOH_T / VOL_T             ← 输出高低电平带载能力
  ↓
VIL_T / VIH_T             ← 输入阈值扫描
  ↓
FUNC_T                    ← 真值表 pattern（11 个向量起）
  ↓
SetPassBin
```

对照组：`CD4511_v1` 官方工程的 8 项正是 OSN / OSP / IIL / VOH / VOL / IDD / FUNC / SetPassBin —— **直接照它的结构改 signal 名即可**。

## 6. 配套工程模板

`templates/HC138_OS_V1/` 是已验证可解析的完整骨架：

```
HC138_OS_V1.job   .res  .sig  .grp  .tim  .pat  .tmf
pattern/func.csv
Test.cpp   Makefile   interface.h
```

`.tmf` 中 3 个测试项：

| FN | FuncName | Sbin/Hbin | 参数数 | Limit |
|:--:|---|:--:|:--:|---|
| 0 | OSN_T | 2 / 2 | 14 | −1.2 ~ −0.2 V |
| 1 | OSP_T | 3 / 3 | 14 | 0.2 ~ 1.2 V |
| 2 | SetPassBin | 1 / 1 | 1 | Pass |

参数顺序（实际名称为 `OSN__A0` / `OSP__A0` 形式的双下划线前缀）：
`A0, A1, A2, E1, E2, E3, Y0, Y1, Y2, Y3, Y4, Y5, Y6, Y7`

> `ResultAnalysis` 的顺序必须与 `Measure()` 返回数组顺序严格一致，否则会判错脚。用 `scripts/tmf_dump.py -v` 可直接核对。

⚠️ **Limit 目前是沿用的 CD4511 标定值，不是 HC138 的实测值。**上机前必须按 `07-Limits标定与六条坑.md` 重新标定。
