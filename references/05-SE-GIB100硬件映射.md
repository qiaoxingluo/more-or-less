## 1. 核心公式

```
插槽针号 = 32 − CHn
```

即：`.sig` 里写的 `Site0_CH = 1:1:N`，对应到插槽上的物理针号就是 `32 − N`。

这个「倒序」是硬件布线造成的，**第一次接板极易接反** —— 接反后现象是全组管脚读数异常（因为 PPMU 实际连到了别人的脚上）。

## 3. 电源与地 —— 最容易接错的地方

| 网络 | 插槽针位 | 说明 |
|---|---|---|
| **DPS Force / Sense CH0** | **c32 / b32** | `.sig` 里 `VCC → DPS 1:1:0` |
| **GND（系统地）** | **b7** | DUT 的地接这里，**不占 ATE 通道** |
| ⚠️ **AGND（模拟地）** | b2 / b5 / b12 / b17 / b23 / b28 | **不是同一个网络！** |

### 3.1 GND 为什么不占 ATE 通道

GND 在物理上硬连接到测试机系统地的低阻平面。它不需要 SMU/PPMU 驱动，因此：

- **不出现在 `.sig` 里**；
- 不消耗 DIO / DPS 通道数；
- 但要**自己把线焊到 b7**（或用板上预留的 GND 端子）。

### 3.2 AGND ≠ GND —— 血的教训

AGND 是**模拟地**，与数字系统地 GND 在板上通过特定网络（磁珠 / 0 Ω 电阻 / 单点连接）隔离或相连，**电位不一定相等**。

⚠️ 把 DUT 的地错接到 AGND：

- OS 测试的 GND 回路电位漂移 → 所有 Vf 读数平移 → **全批误判**；
- 精密 DC 参数（Leakage、ADC）噪声抬升量级；
- 严重时形成地环路，干扰整块板的模拟资源。

**接线前用万用表通断档确认 GND 与 b7 连通、与 b2 不连通。**

## 4. 接线核对清单（每次换 DUT 都过一遍）

- [ ] VCC → DPS Force/Sense，`.sig` 中 AFEType = `DPS`, ChType = `Supply`
- [ ] GND → **b7**（不是 AGND)，且 `.sig` 中**没有** GND 条目
- [ ] 每个信号脚按 `插槽针号 = 32 − CHn` 接线，没有整体错位一格
- [ ] 自焊线完成后逐根打通断，确认无虚焊 / 相邻线相碰
- [ ] 上电前 DPS 限流已设好（防止 VCC-GND 反接烧片）
- [ ] 板上若有上拉电阻（如 I²C），确认 OS 时会被继电器断开（见 `03` 第 8.5 节）

## 5. 自焊线板的额外风险

接插式适配器和自焊杜邦线相比，前者是工厂保证接触的，后者完全靠手工：

| 失效模式 | 表现为 | OS 能否抓到 |
|---|---|---|
| 杜邦线没插到底 / 虚焊 | 某脚开路 → 读数打到 ±2 V 钳位 | ✓ |
| **相邻两根线铜丝相碰** | **相邻脚短接** | **✗（并行法盲区）** |
| 焊盘连锡 | 同上 | **✗** |
| 线序错位一格 | 多脚读数集体异常、pattern 全错 | ✓（但难定位） |

⚠️ **这正是推荐双轮奇偶法的直接理由**：自焊线场景下「相邻脚短接」是高频失效，而课件标准的并行 OS 恰好抓不到它。详见 `03-开短路OS方法论.md`。
