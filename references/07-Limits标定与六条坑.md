# Limits 标定方法与六条工程坑

## 第一部分：限值标定

### 1. 核心认知 —— 限值不是查出来的，是标定出来的

最常见的作业 / 新人错误：**把 0.2 / 1.2 当成规格书数字抄过来。**

理由很简单：OS 测的是 ESD **保护**二极管的正向压降 Vf。保护二极管不是功能电路，**datasheet 上不会给它的 Vf 规格**。它的离散性很大，不同批次、不同封装、不同温度都会变。

### 2. 各家窗口对比 —— 它们彼此都对不上

| 来源 | 下限 | 上限 |
|---|---|---|
| ST2500 手册 / `CD4511_v1.tmf` 工程 | 0.2 V | 1.2 V |
| 通用业界口径 | 0.2 V | 1.5 V |
| 期刊《基于 ATE 的 IC 测试原理、方法及故障分析》 | 0.1 V | 1.2 V |
| **课件 PPT `7.课件（CD4511）` 第 15 页** | 0.2 V | **0.8 V** ⚠️ |

⚠️ **同一门课的 PPT 与工程文件就打架**：PPT 写 0.8 V，`CD4511_v1.tmf` 写 1.2 V。

**裁决原则：发生分歧时以随工程下发的 `.tmf` 为准。**

原因：PPT 是讲稿，`.tmf` 是实际跑过的配置。0.8 V 上限会把 Vf 偏高但完全正常的管子误杀 —— 在量产里这就是实打实的**良率损失**。

### 3. 标定四步

| 步 | 动作 | 要点 |
|:--:|---|---|
| 1 | **放宽窗口跑良品** | 设 0.05 ~ 1.8 V，跑 **30~50 颗已知良品** |
| 2 | **统计 μ 与 σ** | 每根脚分别统计，收紧到 **μ ± 6σ** |
| 3 | **叠加 GR&R** | Gauge Repeatability & Reproducibility —— 设备本身的复现性误差要预留 |
| 4 | **跑坏品验证分离度** | 拿故意破坏的样品（如挑掉一根键合线），确认**良品簇与失效簇之间有清晰间隔**才算定稿 |

> 第 4 步最关键也最常被跳过。**没有坏品验证过的窗口，等于没有标定。**

### 4. 两个必须记住的量

#### 4.1 电压钳位必须设在窗口之外（通常 ±2 V）

```cpp
.VoltClamp(2, -2)      // ✅ 窗口 ±(0.2~1.2)V，钳位 ±2V 在窗口外
.VoltClamp(1.2, -1.2)  // ❌ 钳位与窗口边界重合
```

原理：开路引脚没有电流回路，PPMU 会把电压推到钳位值。若钳位正好等于窗口边界，开路的读数落在 ±1.2 V —— **落在 PASS 区里，判不出来**。必须让钳位远离窗口，使开路读数明确落在 FAIL 区。

#### 4.2 电流不要超过 ~100 µA

OS 是**真的让 ESD 二极管正向导通**。电流过大时：

- 局部发热改变 Vf（自加热效应），读数不稳；
- 极端情况会损伤 ESD 保护结构本身。

业界普遍取 100 µA，是安全裕量与信噪比的折中。

## 第二部分：六条工程坑

### 坑 1 —— VCC 必须被 DPS 强置 0 V

OS 测上二极管（OSP）时，电流路径是：

```
PPMU → 引脚 → 上二极管 → VCC → (低阻通路) → GND
```

**这条回路依赖 VCC 是一条低阻通路。** 如果 VCC 悬空（DPS 没接或没驱动）：

- 上二极管没有回路；
- PPMU 注入的 100 µA 无处可去 → 电压被推到钳位 +2 V；
- 结果：**全好芯片也会报"整批开路"**。

这就是 `CD4511_v1/Test.cpp` 里这一行的全部意义：

```cpp
dps.Signal("VDD").SetMode("FVMV").VoltForce(0)
                 .CurrRange(0.5).CurrClamp(0.5, -0.5).Execute();
```

⚠️ 注意是 **VoltForce(0)** —— 不是断电，是**主动驱动到 0 V**。断电（DisConnect）等于悬空，同样出错。

---

### 坑 2 —— GND 不占 ATE 通道，但要接对座

GND 硬线连接到测试机系统地的低阻平面：

- 它**不出现在 `.sig` 里**；
- 不消耗 DIO / DPS 通道；
- 但**必须自己把线焊到正确的座**（SE-GIB100 上是 **b7**）。

⚠️ **AGND（模拟地）在 b2 / b5 / b12 / b17 / b23 / b28**，与 GND **不是同一个网络**。

把 DUT 地错接 AGND 的后果：

- OS 的 GND 回路电位漂移 → 所有 Vf 读数整体平移 → **全批误判**；
- 精密 DC 参数（Leakage、ADC）噪声抬升；
- 严重时形成地环路，干扰整块板的模拟资源。

**接线前用万用表通断档确认 GND 与 b7 连通、与 b2 不连通。**

---

### 坑 3 —— 电源脚不能被当成普通 IO 测

VCC / GND 内部结构不同，标准 OS 限值不适用。

**但症状本身就是极好的诊断信息：**

| 现象 | 诊断 |
|---|---|
| 所有 **OSP** 集体失效，OSN 正常 | **VCC 脚开路 / 没接好** |
| 所有 **OSN** 集体失效，OSP 正常 | **GND 脚开路 / 没接好** |
| 单脚失效 | 该引脚自身问题（虚焊、连锡、ESD 损伤） |

实证：ADC0832 工程的 `.tmf` 里，VCC **只有 `OSN_VCC_DIO` 而没有对应的 OSP** —— 官方同样不把电源脚当普通 IO 处理（见 `08` 第 1 节）。

---

### 坑 4 —— 板上的上拉电阻会污染结果

I²C 器件的 SDA / SCL **必然**有上拉电阻接到 VCC。

做 OS 时 VCC 被强置 0 V，于是：

```
上拉电阻把被测脚拽向 0 V
  → 注入的 100 µA 被电阻分流
  → 二极管实际电流不足 100 µA
  → Vf 读数偏离，甚至落在窗口外形成假失效
```

**官方解法**：HK24C02 案例明确要求**用继电器（CBIT）物理断开上拉电阻**。

> 推论：画 loadboard 时，凡是带外部上拉 / 下拉的引脚，都要预留继电器隔离开关。这是**硬件阶段**就要决定的事，事后改不了。

---

### 坑 5 —— 温度漂移约 −2 mV/°C

二极管 $V_f$ 随温度上升而**下降**，约 **−2 mV/°C**。

| 温度 | Vf（标称 0.65 V @ 25 °C） | 在 0.2 ~ 1.2 V 窗口内？ |
|---|---|---|
| 25 °C | 0.65 V | ✓ |
| 85 °C | ≈ 0.53 V | ✓（余量仍够） |

⚠️ **反过来说是致命的**：如果为了"提精度"把下限从 0.2 V 提到 **0.5 V 以上**，高温下良品 Vf 会跌破下限 → **一定会误杀**。

**这是「收紧限值 = 提高精度」这一直觉的反例** —— 收紧前必须先算温度余量。

---

### 坑 6 —— 采样前必须留建立延时

```cpp
ppmu.Signal("INOUT_PINS").SetMode("FIMV").CurrForce(-100e-6)...Execute();
sys.DelayUs(5000);                                     // ★ 必须有
ppmu.Signal("INOUT_PINS").Measure(OSN_RESULT);
```

去掉延时读到的是**瞬态**，里面混着：

- 引脚寄生电容的充电过程；
- 二极管结电容的建立过程；
- PPMU 负反馈环路本身的建立时间。

后果：数据飘 → σ 变大 → **μ ± 6σ 窗口被撑到失去判别力**，标定直接失败。

**推荐值**：`sys.DelayUs(5000)`（5 ms），与 `CD4511_v1` 样例一致。

## 第三部分：调试 Checklist

遇到 OS 结果不对时按顺序排查：

| 现象 | 先查 |
|---|---|
| **所有脚都 FAIL** | 坑 1：DPS 有没有把 VCC 强置 0 V |
| **OSN 全 FAIL / OSP 全 FAIL** | 坑 3：GND 或 VCC 没接好 |
| **读数全部偏移一个固定量** | 坑 2（接到 AGND）或坑 5（温度） |
| **读数随机跳动、σ 很大** | 坑 6：缺建立延时 |
| **只有 I²C / 带上拉的脚异常** | 坑 4：上拉电阻没断开 |
| **相邻短接的坏品跑 PASS** | **不是故障**，是并行法盲区 → 换双轮奇偶法（见 `03`） |
| **换 DUT 后全乱** | 接线错位一格，核对 `插槽针号 = 32 − CHn`（见 `05`） |

## 附：单位换算速查

| 量 | 换算 |
|---|---|
| 电流 | 1 mA = 10³ µA；OS 用的 100 µA 在 C++ 里写 `100e-6` |
| 电压 | 1 V = 10³ mV |
| 时间 | 1 ms = 10³ µs = 10⁶ ns |
| 频率 | 1 MHz = 10³ kHz = 10⁶ Hz |
| dB | 电压比取 $20\log_{10}(V_1/V_2)$；CMRR / PSRR 的单位就是 dB |
