# st2500-ate-test-skill

面向**加速科技 ST2500 / ST2516 ATE 平台**的集成电路测试工程 skill，把这套课程资源里的知识沉淀成可复用、可查证的形式。

> 平台：ST2500 / ST2516 + SE-GIB100 通用器件接口板
> 知识来源：《【课程资源】集成电路测试》课件、五款官方案例工程、技术手册
> 整理日期：2026-10-28

## 这个仓库解决什么问题

在 ST2500 上开发一个 DUT 测试工程，最容易卡在三类地方：

1. **术语不通** —— 同一个缩写在不同语境下意思完全不同（最典型：**ST2500 的 SMU ≠ 业界的 Source Measure Unit**）；
2. **文件体系不熟** —— `.job/.res/.sig/.grp/.tim/.pat/.tmf/Test.cpp` 九个文件互相索引，改错一个全盘皆输，而且 `.tmf` 里 **FuncList 藏在 `SiteList[0]` 下**、还**带 BOM**；
3. **限值照抄** —— 把别人的 0.2 / 1.2 V 当成规格书数字直接抄，**限值从来是标定出来的，不是查出来的**。

除此之外，本仓库还记录了一个在课程学习中发现的**原理级结论**：

> **课件标准的并行 OS（开短路）方案，抓不到相邻引脚短接。**
> 两根短接的引脚各自 force 100 µA → 短接节点共 200 µA → 由**两只并联的下二极管**分摊 → 每只仍是 100 µA → Vf 是电流的对数函数 → **读数完全不变 → 双双 PASS**。
> 调紧限值救不了，因为读数根本没有偏移。
> **解法**：双轮奇偶法（Odd/Even Two-Pass），把「分流」变成「硬短路」，读数被拉到 ≈0 V → 硬 FAIL。而且它和原方案**测量次数相同（都是 2 次），却多覆盖了一类失效 —— 纯赚。**

详见 [`references/03-开短路OS方法论.md`](references/03-开短路OS方法论.md)。

## 快速开始

### 1. 复用工程模板

```bash
cp -r templates/HC138_OS_V1  D:/MINI-ATE/workspace/<新工程名>
cd D:/MINI-ATE/workspace/<新工程名>
make                       # 产出 Test.dll
```

模板已实现课件标准的并行双向 OS（`.tmf` 通过 JSON 往返校验，14 个参数顺序已确认）。

### 2. 按五步法改造（顺序不可乱）

| 步 | 改什么 |
|:--:|---|
| 1 | `.sig` Signal Map |
| 2 | `.grp` Signal Group |
| 3 | `.tim` Timing |
| 4 | `.tmf` 测试流程 |
| 5 | Limit（**必须实测标定**，见 references/07） |

### 3. 查阅已有工程的测试项

```bash
python scripts/tmf_dump.py <目录>        # 概览
python scripts/tmf_dump.py <目录> -v     # 附带 Min/Max/Unit
```

脚本内部已处理两个坑：`encoding='utf-8-sig'` 与 `SiteList[0].FuncList[]`。

## 几条必须记住的结论

| # | 结论 |
|:--:|---|
| 1 | **ST2500 的 SMU 是高压电源板卡，不是 Source Measure Unit。** 真正的源测量由 PPMU / BPMU 承担。 |
| 2 | **OS 必须把 VCC 用 DPS 强置 0 V**（`VoltForce(0)`，不是 `DisConnect`）。否则整批误报开路。 |
| 3 | **GND 不占 ATE 通道**，SE-GIB100 上接 **b7**；**AGND（b2/b5/b12/b17/b23/b28）是模拟地，绝不能当地接。** |
| 4 | **插槽针号 = 32 − CHn**，倒序。第一次接板极易接反。 |
| 5 | **并行 OS 抓不到相邻脚短接**，且调紧限值无效 —— 换双轮奇偶法。 |
| 6 | **限值冲突时以随工程下发的 `.tmf` 为准**（同一门课 PPT 写 0.8 V、`.tmf` 写 1.2 V）。 |
| 7 | **电流不超过 ~100 µA**、**钳位设在窗口之外（±2 V）**、**采样前必须 `sys.DelayUs(5000)`**。 |
| 8 | **Test.cpp 没有 main()**；每个函数必须包 `TEST_BEGIN / TEST_ERROR / TEST_END` 并在结尾复位到 0 V 后 `DisConnect()`。 |
| 9 | **不存在 "HCE138" 这个型号**，应为 74HC138。若为 **74LS138（TTL）**，则没有 VCC 侧二极管，**只能跑 OSN**。 |
| 10 | **带上拉的引脚（I²C 的 SDA/SCL）做 OS 前必须用继电器断开**，否则读数被上拉电阻拖偏。 |
